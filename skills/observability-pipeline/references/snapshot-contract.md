# 快照契约参考

## 最小字段

```json
{
  "schema_version": 1,
  "status": "ok",
  "captured_at": "2026-01-01T00:00:00Z",
  "last_attempt_at": "2026-01-01T00:00:00Z",
  "source": {"id": "example", "url": "https://example.com"},
  "error": "",
  "items": []
}
```

根据板块增加 `warnings`、`retention`、`summary` 和 `sources`，不要为迎合示例硬填无意义字段。

## 时间与状态

- `captured_at` 只在成功获得有效数据时更新。
- `last_attempt_at` 只在真实发起采集尝试时更新；未尝试不能前进。
- `ok`：本次成功；`partial`：部分成功；`stale`：本次失败并沿用旧快照；`unavailable`：没有可用数据。
- `unknown` 用于来源不足以判断的情况，不等于失败、成功或 0。
- 快照时间早于已有数据时拒绝覆盖，防止旧响应回退新状态。

## 指标口径

- 滚动近 30 天下载、历史累计、相邻快照净变、恰好 30 天前净变分别命名。
- 没有恰好日期基线时显示未知，不插值、不按 0。
- 账户总量受对象加入、消失和改名影响；对象级同 id 对比更可靠。
- 相邻净变只统计两个快照都存在且指标可用的对象。
- 实测与来源自报并列保存，不相加、不相除、不互相校正。

## 关系与引用

- 只保存稳定 `domain:id` 引用，指标仍归原快照所有。
- `resolved`：当日来源中确实存在；`unresolved`：来源可用但目标不存在。
- `unchecked` 或 `missing_index`：来源不可用，不能推断目标消失。
- `out_of_scope`：目标不属于当前核对范围，不是断链。
- 只有已核对关系才发布“当天见到”的强链接断言。

## 历史与差异

- 首次采集只建基线，不把全量写成新增。
- 差异按稳定 id 与内容签名计算，采集状态和 URL 变化不应刷新“作者修订”。
- 沿用旧数据的日期不解释为零增长或清单停止更新。
- 样本过少时不解释趋势；排期预测和真实观测分开。
- 保留窗口、去重键、截断与预算命中必须公开，避免制造虚假全量。

## 安全与预算

- 网络请求设置超时、响应大小、页数、重试和总抓取预算。
- 令牌不进入公开 JSON、日志、URL 或前端持久存储。
- 第三方文本在渲染时转义，链接只接受明确白名单。
- CSV 对 `= + - @` 开头的单元格做公式注入防护。
- 超预算时优先削样本而非计数；身份台账被截断时将后续差异标为不可比或下限。
