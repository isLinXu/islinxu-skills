# 数值与实验检查清单

按实际代码路径选择检查项，不要求为每个项目机械覆盖全部条目。

## 随机性与状态

- 固定 Python、框架和 CUDA 相关种子，记录确定性设置及其性能代价。
- 区分训练与评估模式，检查 dropout、BatchNorm、路由和采样状态。
- 检查 DataLoader worker、分布式 rank 和 checkpoint 恢复后的随机状态。
- 保存代码、依赖、硬件和关键环境信息，避免只有权重无法复现。

## 数值稳定

- 浮点相等比较改用与尺度匹配的容差；不要对所有场景使用同一个 epsilon。
- 检查归一化、除法、log、sqrt、softmax 和掩码路径的零值、空值与极值。
- 检查 fp16/bf16 累加、损失缩放、梯度裁剪和 NaN/Inf 传播。
- 构造空张量、单元素、重复值、超长序列、全掩码和非法形状反例。
- 检查设备与 dtype 隐式转换，以及跨后端算子语义差异。

## 数据与标签

- 核对训练、验证和测试划分，检查重复样本、近重复和预处理泄漏。
- 验证标签索引、坐标系、图像尺寸、padding、缩放和增强后的对应关系。
- 检查缓存键是否包含所有影响结果的配置，避免复用错误产物。
- 统计空标签、异常框、缺失模态和解析失败，不静默丢弃后改变分母。

## 训练与优化

- 确认学习率、batch、梯度累积和分布式世界规模的换算口径。
- 检查冻结参数、优化器参数组、权重衰减和混合精度白名单。
- 对 MoE 检查路由 top-k、容量、负载均衡、专家剪枝与合并语义。
- 验证 checkpoint 包含模型、优化器、调度器、步数和必要随机状态。

## 评测与比较

- 基线和候选共享数据、预算、预处理、后处理和评测脚本版本。
- 同时保存原始输出与解析结果，解析失败不能直接算成标签错误。
- 保留样本数、分母、缺失项和失败项，比例变化能回到计数。
- 单次小幅差异先估计噪声，不通过挑选最佳复跑制造提升。
- 最小冒烟通过后回到原始失败命令和完整流程复核。
