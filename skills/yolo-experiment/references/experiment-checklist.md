# YOLO 实验清单

## 开跑前

- [ ] 记录代码提交、模型 YAML、权重来源、数据配置和依赖环境。
- [ ] 明确唯一研究变量及会被结果改变的决策。
- [ ] 基线与候选共享数据划分、输入尺寸、增强、预算和评测脚本。
- [ ] 固定或记录种子、batch、梯度累积、学习率、精度和硬件。
- [ ] 设置显存与耗时预算、checkpoint 策略和停止条件。
- [ ] 写清最小冒烟、分层回归与完整验收命令。

## 模型配置与前向

- [ ] 实际解析后的模块与 YAML 一致，参数和输出形状符合预期。
- [ ] 检查分类、回归、置信度和辅助分支的张量语义。
- [ ] 小 batch 前向、反向无 NaN/Inf，梯度和显存处于可解释范围。
- [ ] 训练与评估模式切换正确，预训练权重加载无未解释的缺失键。
- [ ] MoE 路由覆盖 top-k、空输入、边界容量、专家负载与剪枝调度。

## 数据与训练

- [ ] 标签索引、框坐标、马赛克、缩放、padding 和翻转后的对应关系正确。
- [ ] 空标签、越界框、损坏图像和重复样本有明确处理与计数。
- [ ] 短训练损失路径正常，验证集未进入训练或增强统计。
- [ ] 恢复训练包含优化器、调度器、步数与必要随机状态。
- [ ] 长训练日志能映射到配置、权重和结果，不依赖会话记忆。

## 评测与效率

- [ ] mAP、召回、精确率和类别指标的 IOU、置信度与 max-det 口径明确。
- [ ] 小目标、遮挡、类别和难度切片保留样本数与失败示例。
- [ ] 参数量、FLOPs、显存、吞吐和延迟注明输入、batch、设备、预热和精度。
- [ ] 单次小幅差异不直接写成提升；必要时重复运行或多种子估计波动。

## 导出与部署

- [ ] 导出模型、运行时和目标后端分别验证，不只做“导出成功”检查。
- [ ] 固定输入下比较源模型与导出结果的形状、分数和框坐标。
- [ ] 动态 shape、NMS、量化、算子支持和后处理差异有单独结论。
- [ ] 部署延迟包含哪些预处理、推理和后处理阶段写清楚。
- [ ] 中间层修复后回到原始端到端命令复核。

## 结果承接

- [ ] 现行操作写入 Runbook，质量门槛写入 Criterion，结果写入 Records。
- [ ] 失败、跳过、未运行和未验证假设单独列出。
- [ ] 临时绕路、未知根因和剩余风险没有伪装成正式解决方案。
